❓ Media Library Q&A

            

                Hover any toolbar button for a tip. Full write-up:
                MEDIA_LIBRARY_AND_PAIRS.md and README.md in the toolbox folder.
            

            

                How do I start the server from this app?
                
Click ▶ Start Server (or the red offline pill / banner). The page launches the backend and waits for green (up to ~90s). Same button exists on Launcher, VSR, and File Organizer. If the browser blocks it: 🖥 Console, 📂 Open Folder → START SERVER.bat, or run SETUP (run once).bat once, then try Start again.

            

            

                Do tags show in Windows Explorer?
                
Yes, when the server is green and “write tags into file metadata” is on (default). Tags → Explorer Tags; rank → Rating stars. Best on MP4/images; MKV uses .fafo.json sidecars. Search: tag:word or rating:5 stars.

            

            

                If I pair two files then move them to different folders, is the pair broken?
                
The catalog uses path-based IDs, so a move can drop the old UI link. The durable link is the shared UP-#### tag written into both files. After moving: Rescan (auto-relinks) or click Relink Pairs from Tags. Check 🩺 Pair Health. Both folders must still be watched. Optional: export a Pair Map JSON backup.

            

            

                What tags does pairing add?
                
Both files get UP-####. Before also gets source / before / original-video. After gets upscaled / after / vsr / etc. Project tags (client, project name) can be applied to both via the shared-tags checkbox, Push tags button, or batch “pair partners”.

            

            

                Can I put sources and upscales in one folder?
                
Yes. One watched tree is fine. Two roots (e.g. Sources + Upscaled) is optional and simpler for humans, not required by the software.

            

            

                Can I ZIP the library to save space and still play videos here?
                
Not realistically. ZIP/RAR are archives — players need a normal video file to seek and stream. You’d extract first (slow, needs free space). Better: re-encode to HEVC/AV1 MP4 for hot files, or keep cold projects on a USB drive / Archive Pair and re-add that folder when plugged in.

            

            

                Is re-encoding or USB a good long-term plan?
                
Yes. Working set on the PC; archive finished work on USB/external (or re-encode masters). Plug in → Add Folder / Rescan → Relink Pairs. NTFS “compress folder” almost never helps already-compressed video.

            

            

                FAFO new-tab player vs this library?
                
This toolbox organizes, pairs, renames, and bulk-tags. FAFO is the video new-tab player with on-play rate/tag. Explorer writes need the toolbox server or FAFO’s optional companion — toolbox uses dedicated 127.0.0.87:18765; FAFO companion keeps 127.0.0.1:8765. Start the toolbox server with ▶ Start Server here.
