Scan folder

Find exact and near-exact duplicates across common Windows file types — images, video, audio, documents, archives, and code. Optional cross-source check compares Downloads against already-processed Pre-scaled / After folders without allowing those processed copies to be deleted.

Start the server (▶ Start Server above), pick a folder, then scan. Pause / Cancel live only in this left dock.

Inbox = Downloads / new files (can recycle). Before = Pre-scaled originals after processing (locked — keep rule uses this). After = 4K/96fps post-upgrade (locked, matched by _PID_xxxxxxxx from the pre-scaled name — not by size). Leave Before empty to turn the keep-Pre-scaled rule off.

Options

Keep rules

Top rule wins (use ▲ or Top). Keep Pre-scaled is built in: if a Before folder is set in Cross-source, keep that copy and recycle Inbox duplicates so you do not re-process. Leave Before empty (or uncheck the rule) to turn it off.
