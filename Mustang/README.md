# FAFO Auto Mechanic

Open `Toolbox Launcher.html` and choose **FAFO Auto Mechanic**, or use the **FAFO Auto Mechanic** shortcut on the Desktop. Both start the private repo at `C:\_Git\repos\html\FAFO-Auto-Tech` (`npm run dev` on port 8080). Launching does not copy files in either direction.

Edit that private repo. Do not edit this folder. On this PC, `Mustang/index.html` opens `launch.html` instead of the old page. GitHub Pages still serves the old snapshot at `Mustang/index.html` until a finished version is published on purpose.

The desktop shortcut is a normal Windows shortcut. Right-click it, open Properties, and choose Change Icon. `Change-FAFO-Auto-Tech-Icon.bat` does the same and keeps the icon in `Custom Icons and Theme\Completed ICO\Custom\FAFO-Auto-Tech.ico`.
