Connect a phone on current Android

Android 11 and newer, including Android 16 and 17, hide developer options and use a pairing code. The pairing port and the connection port are two different numbers. This PC already has platform-tools 37, which is the version Android 17 expects.

1. Turn on developer options

  1. Open Settings and find the build number. Pixel: About phone, then tap Build number 7 times. Samsung: About phone, Software information, then Build number. Xiaomi / POCO: My device, All specs, then tap OS version. Oppo, OnePlus, and realme: About device, Version, then Build number.
  2. Enter the phone lock PIN if it asks.
  3. Open Developer options. Pixel: System, Developer options. Samsung: search Settings for Developer options. Xiaomi: Additional settings. Oppo and realme: System & update, or Additional settings.

2. Turn on the two debugging switches

  1. Turn on USB debugging.
  2. On Xiaomi, Redmi, and POCO also turn on USB debugging (Security settings). That second switch is what lets a PC read battery stats.
  3. Turn on Wireless debugging. When it asks about this Wi-Fi, allow it and check Always allow on this network. The phone and this PC must be on that same Wi-Fi. Guest Wi-Fi and a VPN on either side block it.

3. USB, the first time

  1. Unlock the phone. The allow dialog does not appear on the lock screen.
  2. Plug it into this PC. If Windows only charges the phone, pull down the USB notification and choose File transfer / Android Auto, not Charging only.
  3. On the phone tap Allow, and check Always allow from this computer.
  4. Come back here and press Scan now. If the status stays unauthorized, in Developer options tap Revoke USB debugging authorizations, unplug, plug back in, and allow it again.

4. Wireless, when you do not want the cable

  1. On the phone tap the Wireless debugging row itself, not only the switch.
  2. Write down the IP address and port on that page. That port is the connection port.
  3. Tap Pair device with pairing code. A new dialog shows a 6-digit code, the same IP, and a different port. That port is the pairing port. It expires in about a minute.
  4. Type those four values below and press Pair. Leave the code dialog open until this page says the phone is connected.
  5. Then press Scan now.

5. After the first pair

On Android 17, with platform-tools 37, a phone that you paired and set to always allow this network reconnects by itself the next time it joins that Wi-Fi. You only press Scan now. Android 11 through 16 stay paired, but you may need to open Wireless debugging again and press Pair if the status says no phone.

6. What the scan can see

  • One scan is the battery percent plus Android’s total since the last full charge. It is not “the last hour” until you sample more than once.
  • Press Sample every 15 min and leave this page’s server running. The table then shows what increased between samples.
  • Screen, phone radio, and each app are listed in milliamp-hours. A desktop PC with no battery still lists busy programs, not watt-hours.
  • Some Samsung and Xiaomi builds connect and still omit the per-app list. Percent, temperature, and current are still recorded.
  • A system update can turn Developer options off. If Scan now stops seeing the phone, check the two switches again.
