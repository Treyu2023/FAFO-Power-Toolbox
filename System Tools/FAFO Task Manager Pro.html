Task Manager Pro

Live processes with what it is, disable pros/cons, efficiency scoring, and optional weekly CVE checks for apps that actually ran on this PC.

Data strategy (recommended): There is no free complete “ProcessLibrary API.” This tool uses (1) a local curated knowledge base, (2) live CPU/RAM on your machine, and (3) optional NVD keyword CVE lookups only for apps you’ve seen — not a full internet crawl of every EXE.

Efficiency modes

Three kill groups. Check apps on the process list and use Add selected, or toggle M1/M2/M3 on a row. Kill all in this group ends every running copy of those names, including ones past the first screen of the list.

Safety: Hard-protected system processes (csrss, lsass, services, …) are never killed. By default, processes marked not safe to disable are skipped. Turn that off only if you mean to. Force kill is a separate, more aggressive end.

Options

Groups are saved on this PC (and mirrored in this browser) by process name, not PID. The same app can sit in more than one group.
