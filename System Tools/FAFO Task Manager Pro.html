Task Manager Pro

Live processes with what it is, disable pros/cons, efficiency scoring, and optional weekly CVE checks for apps that actually ran on this PC.

Data strategy (recommended): There is no free complete “ProcessLibrary API.” This tool uses (1) a local curated knowledge base, (2) live CPU/RAM on your machine, and (3) optional NVD keyword CVE lookups only for apps you’ve seen — not a full internet crawl of every EXE.

Efficiency modes

Three kill profiles. Assign processes with the M1/M2/M3 toggles on the process list — the same process can sit in all three modes. Press a mode button to end every matching running process in that list.

Safety: Hard-protected system processes (csrss, lsass, services, …) are never killed. By default, processes marked not safe to disable in the knowledge base are also skipped unless you enable force below.

Options

Mode membership is stored in this browser (by process name, not PID). Overlap is intentional — e.g. Discord can be in Focus + Gaming + Deep clean.
