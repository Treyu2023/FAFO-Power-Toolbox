📋 Ditto Groups

Browse, rename, regroup, edit, and inject clips into Ditto’s SQLite database. Saves close and reopen Ditto so the tray list actually updates.

Ditto caches the database in memory. Reflect in Ditto (on by default) stops Ditto, writes %APPDATA%\Ditto\Ditto.db, then starts it again. Full-file backup is optional — the live DB is multi-GB.
