30-second pitch

TaxForge is a local-first tax-season command center for SMBs on Xero. It doesn’t file taxes — it automates readiness: link or import the ledger, score how tax-ready the books are, clean write-offs, and drive year-end close into a preparer pack that a CPA or Grok can actually use.

What shipped (v1)

🧾
TaxForge Hub — suite home, animated flow, navigation
🔗
LedgerLink Console — Xero bridge: demo org, CoA, CSV import, OAuth scaffold
💓
Compliance Pulse — weighted readiness score + hygiene checklist
🛠️
Write-Off Workshop — triage spend, auto-suggest accounts, export CSV
🎯
Year-End War Room — deadlines, vault, kanban, preparer pack JSON

Talking points for experts

  • Problem: Tax prep fails on dirty books and fragmented tools — not on lack of calculators.
  • Wedge: Preparedness layer between Xero and human/AI review.
  • Security: No client secrets in HTML; OAuth code only; live tokens → loopback + FAFO Secrets later.
  • Demo proof: 5 minutes from demo org → rising Pulse score → cleaner write-offs → preparer pack.
  • Grok fit: Structured pack as grounded context; agents for “explain score / propose codes / find anomalies.”
  • Ask: Domain weights & rules · live Xero proxy design · Grok assist UX.
