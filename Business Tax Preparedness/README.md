# TaxForge — Business Tax Preparedness

Local-first suite for **tax-season readiness** on top of (or importing from) **Xero**. Not tax advice; does not e-file.

## Apps

| File | Name |
|------|------|
| `TaxForge Hub.html` | Suite home |
| `LedgerLink Console.html` | Xero / CSV / demo ledger |
| `Compliance Pulse.html` | Readiness score |
| `Write-Off Workshop.html` | Expense coding |
| `Year-End War Room.html` | Close-out + preparer pack |

Shared: `taxforge-shared.css`, `taxforge-shared.js`
