Subject: TaxForge — local-first tax preparedness suite (Xero) for expert review

Hi team,

I’d like your eyes on a new module in our local FAFO / AI HTML Toolbox: **TaxForge** — a Business Tax Preparedness suite designed to sit in front of (and eventually sync with) **Xero**.

### Why this exists
Tax season fails when books are dirty. TaxForge doesn’t file returns or replace a CPA. It automates *preparedness*: connect/import the ledger, score readiness, clean write-offs, and run year-end close so a human expert—or Grok—gets clean inputs.

### What’s shipped (v1)
Five animated HTML apps under one brand:

1. TaxForge Hub — suite home + recommended flow  
2. LedgerLink Console — Xero bridge (demo org, CoA, CSV import, OAuth client-id scaffold)  
3. Compliance Pulse — animated readiness score + hygiene checklist  
4. Write-Off Workshop — triage spend, auto-suggest accounts, export review CSV  
5. Year-End War Room — deadlines, document vault, kanban, one-click preparer pack (JSON)

Shared local state across apps. No client secrets in the frontend/repo (OAuth code only; token exchange intended for loopback server + FAFO Secrets).

### Demo path (~5 min)
Toolbox Launcher → “TaxForge & Books” → Hub → Load Demo Org in LedgerLink → Pulse → Write-Off auto-suggest → War Room preparer pack.
