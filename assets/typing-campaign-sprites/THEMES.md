# LetterKey art themes (×3)

Switch in-game: campaign panel chips **Glyph / Toon / Rune**. Pref `artTheme`.

| Theme | Look | Source (CC0 Kenney) | Default |
|-------|------|---------------------|---------|
| **glyph** | Geometric players, keys, gems, locks | Abstract Platformer | yes (LetterKey brand) |
| **toon** | Cute blob characters + critters | New Platformer + Simplified | |
| **rune** | 16px dungeon knights / 1-bit tiles | Tiny Dungeon + 1-Bit Pack | |

Each theme has:

- `players/` — 10 classes (6 starters + Raider/Oracle/Titan/Sovereign)
- `companion/glyph.png`
- `bosses/` — warden, serpent, sovereign
- `npcs/` — every campaign territory id
- `bg/` — meadow / road / throne where the pack has backgrounds

Imagine cinematic portraits stay in `imagine/POINTERS.json` (too large to ship as defaults).
