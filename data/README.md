# Toolbox portable data

| File | Purpose |
|------|---------|
| `ip_profiles.json` | IP Profile Switcher setups (home/office/lab, etc.) |

## Move to another PC

1. Copy the whole **AI HTML TOOLBOX** folder, **or**
2. Copy just `data\ip_profiles.json` into the same path on the other machine.

You can also use **Export / Import** inside **IP Profile Switcher**.
