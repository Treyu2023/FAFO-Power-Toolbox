👻 Ghost Device Cleaner

Removes phantom monitors and other disconnected devices that can cause brief black-screen flashes when Windows re-scans your displays.

  • Only targets devices marked phantom or unknown
  • Skips active monitors, NVIDIA GPU, and system devices
  • Defaults to monitor/display ghosts plus stacked PlayStation VR2 entries
  • Opens a picker window so you select which devices to remove
  • Requires typing YES after selection before deleting
  • Writes a log under the tool’s logs folder
Browsers cannot run .bat files from a web page (they only download them). This page launches the cleaner through the S1 toolbox server or the aitoolbox://ghost protocol — then approve the UAC prompt.
Ready — click Run to launch elevated PowerShell.
Fallback if nothing happens: open Explorer → GhostDeviceCleaner\Run-Cleaner-Elevated.bat · or run aitoolbox://ghost after SETUP.
