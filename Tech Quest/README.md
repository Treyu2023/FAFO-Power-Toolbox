# TECH QUEST · ANY Key Chronicles

**v2.0** — Shining Force × Final Fantasy Tactics style campaign for C-store / fuel field techs. Dark humor. Big roster. Gear. Recruits.

## Open

Toolbox Launcher → **Games** → **TECH QUEST** · or `Tech Quest/Tech Quest.html`

## Systems

- **XP / levels**, weapons & armor (class restrictions)
- **Shops** between tickets
- **Deploy** up to party cap per map
- **d20 attack rolls** with On-Call / Per Diem modifiers
- **Hidden Treasure Room** on title menu (before deploy)
- SFX **off by default**
